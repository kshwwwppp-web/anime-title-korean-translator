Anime Title Korean Translator 개인정보 처리방침

시행일: 2026-10-03 · 버전 1.0

요약: 이 확장 프로그램은 사용자가 허용한 사이트에서 애니메이션 제목 문자열을 읽어 한국어 제목을 표시합니다. 개발자가 운영하는 별도 서버로 사용자의 계정 정보, 쿠키, 페이지 전체 내용 또는 브라우징 기록을 수집하지 않습니다.

1. 처리하는 정보

확장 프로그램은 (a) 사용자가 직접 등록한 적용 사이트 도메인, (b) 사용자가 직접 등록한 수동 치환 규칙, (c) 페이지에서 제목 후보로 감지된 텍스트 문자열, (d) 자동 번역 결과 캐시를 처리할 수 있습니다.

2. 정보의 이용 목적

적용 사이트와 치환 규칙은 사용자가 선택한 페이지에서 기능을 실행하기 위해 사용합니다. 제목 문자열은 작품을 식별하고 한국어 제목을 찾거나 번역하기 위해서만 사용합니다. 번역 결과 캐시는 같은 제목에 대한 불필요한 네트워크 요청을 줄이기 위해 사용합니다.

3. 외부 서비스로의 전송

자동 번역 기능을 사용할 때 제목 문자열이 다음 서비스로 전송될 수 있습니다: AniList GraphQL API, Wikimedia/Wikipedia API, Google Input Tools, Google Translate 관련 엔드포인트. 전송은 HTTPS를 사용합니다. 각 서비스의 데이터 처리는 해당 서비스의 정책이 적용됩니다.

4. 저장 위치와 보관

적용 사이트와 수동 치환 규칙은 chrome.storage.sync에 저장될 수 있으며 사용자의 Chrome 동기화 설정에 따라 Google 계정과 동기화될 수 있습니다. 번역 캐시는 chrome.storage.local에 저장됩니다. 개발자는 별도 서버에 이 데이터를 저장하지 않습니다.

5. 판매·광고 및 제3자 제공

개발자는 사용자 데이터를 판매하지 않으며, 개인 맞춤 광고·리타게팅·신용평가 등의 목적으로 사용하지 않습니다. 제목 문자열은 위 3항의 번역/작품 식별 기능 수행에 필요한 범위에서만 외부 서비스에 전송될 수 있습니다.

6. 사용자의 제어

사용자는 언제든 전체 기능을 끄고, 적용 사이트 또는 치환 규칙을 삭제할 수 있습니다. 설정 화면의 “번역 캐시 삭제” 버튼으로 로컬 번역 캐시를 지울 수 있으며, 확장 프로그램을 제거하면 Chrome이 해당 확장 프로그램의 로컬 저장 데이터를 정리합니다.

7. 권한

storage: 설정과 번역 캐시 저장. scripting: 사용자가 명시적으로 허용한 사이트에서만 제목 표시 스크립트를 실행. 사이트 접근 권한은 설치 시 전체 웹사이트에 강제로 부여하지 않고, 사용자가 적용 사이트를 추가할 때 해당 HTTPS 도메인에 대해 요청합니다.
