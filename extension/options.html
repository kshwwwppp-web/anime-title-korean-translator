개인정보 안내
자동 번역을 켜면 페이지에서 감지한 제목 문자열만 작품 식별/번역을 위해 AniList, Wikipedia, Google 번역 관련 서비스로 전송될 수 있습니다. 계정·쿠키·페이지 전체 내용은 개발자 서버로 수집하지 않습니다.

전체 기능 활성화

토글 변경은 저장 버튼과 관계없이 즉시 적용됩니다.

적용 사이트

자동 번역과 수동 치환이 함께 동작할 HTTPS 사이트입니다. 사용자가 추가한 사이트에만 접근 권한을 요청합니다.
내부 적용 예: anime.example.com → https://*.anime.example.com/*

치환 단어

원문에 포함된 문자열이 일치하면 자동 번역보다 먼저 지정한 한글을 표시합니다.
