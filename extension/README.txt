Anime Title Korean Translator v6.0 (Chrome Web Store 공개 배포 준비본)

주요 기능
- 사용자가 직접 허용한 HTTPS 사이트에서만 동작
- 수동 치환 규칙 우선, 미일치 시 자동 한국어 제목 검색/번역
- AniList 배치 조회 + Wikipedia/Google 폴백 + 브라우저 로컬 캐시
- 일본어/로마자/영문 릴리즈 제목 처리
- 설정 토글/사이트/치환 규칙을 열린 탭에 즉시 반영
- 신규 설치는 기능 OFF / 적용 사이트 없음으로 시작
- 개인정보 안내 및 번역 캐시 삭제 제공

설치 테스트
1. chrome://extensions 에서 개발자 모드를 켭니다.
2. '압축해제된 확장 프로그램을 로드합니다'에서 이 폴더를 선택합니다.
3. 아이콘을 눌러 적용 사이트를 추가하고 저장합니다.
4. 사이트 접근 권한을 허용한 뒤 전체 기능을 켭니다.

Chrome Web Store
- 업로드용 ZIP에서는 manifest.json이 ZIP 루트에 있어야 합니다.
- store-docs의 제출 문구와 체크리스트를 확인하세요.
- privacy-policy.html은 별도 공개 HTTPS URL에 호스팅하고 그 URL을 Developer Dashboard에 입력하세요.
