# Chrome Web Store 등록 문구 (한국어)

## 확장 프로그램 이름
Anime Title Korean Translator

## 짧은 설명
사용자가 허용한 웹사이트의 애니메이션 제목을 한국어로 표시하고 수동 치환 규칙을 지원합니다.

## 단일 목적(Single purpose)
사용자가 직접 허용한 웹사이트에서 애니메이션/미디어 제목 문자열을 감지해 한국어 제목을 표시하고, 사용자가 지정한 수동 치환 규칙을 우선 적용합니다.

## 상세 설명
Anime Title Korean Translator는 사용자가 직접 등록하고 접근을 허용한 HTTPS 사이트의 제목 영역을 감지하여 애니메이션 제목을 한국어로 표시하는 도구입니다.

주요 기능:
- 로마자·영문·일본어 제목의 한국어 제목 검색/번역
- 수동 치환 규칙을 자동 번역보다 우선 적용
- 동일 제목은 브라우저 로컬 캐시로 재사용
- 여러 적용 사이트 관리
- 기능 켜기/끄기와 설정 변경을 열린 페이지에 즉시 반영
- 번역 캐시 수동 삭제

자동 번역 과정에서 제목 문자열은 작품 식별 또는 번역을 위해 AniList, Wikipedia, Google 번역 관련 서비스로 전송될 수 있습니다. 개발자가 운영하는 별도 서버는 사용하지 않으며 계정 정보, 쿠키 또는 페이지 전체 내용을 수집하지 않습니다.

페이지 구조가 사이트마다 다르기 때문에 자동 제목 감지는 목록형/미디어 제목 구조를 가진 페이지에서 가장 잘 동작합니다.

## 권한 사용 사유
### storage
사용자가 등록한 적용 사이트, 수동 치환 규칙 및 번역 캐시를 저장합니다.

### scripting
사용자가 직접 접근을 허용한 사이트의 열린 탭에서 제목 표시용 content script를 실행하고, 설정 변경을 새로고침 없이 반영합니다.

### optional host permissions: https://*/*
확장 프로그램이 임의 사이트에 자동 접근하기 위한 권한이 아닙니다. 사용자가 설정 화면에서 도메인을 직접 추가할 때 그 HTTPS 도메인에 대해서만 런타임 권한을 요청하기 위해 선언합니다.

### API host permissions
- graphql.anilist.co: 작품 검색/동의어 확인
- ko/en/ja.wikipedia.org: 한국어 표제어 및 언어 링크 확인
- inputtools.google.com: 일본어 로마자 원문 복원 폴백
- translate.googleapis.com: 제목 번역 폴백

## 개인정보 처리 공개 문구
자동 번역을 사용할 때 페이지에서 제목 후보로 감지한 텍스트 문자열이 AniList, Wikipedia, Google 번역 관련 서비스에 전송될 수 있습니다. 적용 사이트/치환 규칙은 Chrome 저장소에, 번역 캐시는 브라우저 로컬 저장소에 저장됩니다. 개발자가 운영하는 별도 서버로 계정 정보·쿠키·페이지 전체 내용·브라우징 기록을 수집하지 않습니다.
