# 개인정보 처리방침 게시 방법

1. `extension/privacy-policy.html`의 문의 항목에 실제 개발자 이메일 또는 지원 URL을 입력합니다.
2. GitHub Pages, 개인 홈페이지 등 공개 HTTPS 주소에 업로드합니다.
3. Chrome Web Store Developer Dashboard의 Privacy policy URL에 해당 주소를 입력합니다.
4. Dashboard의 데이터 사용/공유 답변은 이 문서 및 실제 확장 동작과 반드시 일치시킵니다.

중요: Chrome Web Store는 로컬 파일 경로나 `chrome-extension://...` 주소가 아니라 사용자가 설치 전에 열 수 있는 공개 URL을 요구하므로, 포함된 HTML 파일 자체만으로 제출 절차가 완료되지는 않습니다.
